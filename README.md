## About

Kira is a Discord music bot built on Lavalink, focused on stable playback and a simple experience. Add it to your server, join a voice channel, and play. Everyday music features work for everyone, and Premium unlocks extra quality, higher limits, and server customization.

## Features

- **Multi-platform playback:** YouTube, Spotify, Apple Music, JioSaavn, and more
- **Lavalink playback:** stable, low-latency audio streaming
- **Smart queue:** play, pause, skip, seek, shuffle, loop, and queue management
- **Autoplay:** keeps the music going when your queue runs out
- **Playlists:** save and load your own playlists
- **Volume control:** adjust playback to fit your server
- **Slash commands and prefix commands:** use whichever you prefer
- **Premium nodes:** higher-quality audio and more music sources for Premium users
- **Custom server profile:** Guild Premium servers can set Kira's avatar, banner, and nickname

## FAQ

**Is Kira free?**
Yes, the core music features are free. Premium is optional and adds higher limits and extras.

**Do I need to vote?**
Some commands are vote-locked on the free plan. Vote Bypass (or User Premium) removes that requirement.

**What is the difference between User and Guild Premium?**
User Premium is tied to your account. Guild Premium applies to one server and benefits everyone in it.

**Can I use commands without a prefix?**
Yes, with the No Prefix plan or User Premium.
